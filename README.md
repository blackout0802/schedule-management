# スケジュール管理アプリ

会社の業務予定・休み（他の社員を含む）・プライベートの予定を1か所で管理する、小規模チーム向けのスケジュールアプリです。
PHP + MySQL だけで動くので、レンタルサーバーにアップロードして使えます（ビルド作業・Node.js は不要）。

## できること

| 機能 | 内容 |
|---|---|
| 業務版 | 会社の全員に見せる画面。**プライベートの予定は、サーバーが返さない**ため、画面を細工しても見えません |
| プライベート版 | 自分のプライベート予定に、**「家族に共有」にした自分の業務・休み**を重ねて表示（家族用リンクで家族に見えるものと同じ。共有は、業務版で予定を開いた「家族にも共有する」のチェック、または共有リンクの「まとめて指定」で決める）。他の社員の予定は出ない（業務版で見る）。以前あった「表示する業務」のチェックは無くなった |
| 休みの管理 | 本人が登録。管理者は他の社員の休みも登録・編集できる（承認は不要） |
| カレンダー | 週ごとの表示。期間のある同じ業務は**1本のバーにまとめ**、土日祝・会社の休業日には出さない。土日祝をはさんで次の週に続くバーは、前後どちらの端も丸くし、「… 」は付けない（土曜から日曜へそのまま続く場合だけ、端を平らにして「… 」を付ける）。**本人の休み（丸1日。半休は除く）の日にも、期間のある業務は出さない**（休みを優先。全部が休みの日なら、そのまま出す）。予定はドラッグで別の日へ動かせる（**期間のある業務は、動かした先の最初と最後の休みの日〔土日・祝日・会社の休業日・本人の休み〕を自動で削る**。日数は増やさない。全部が休みの日なら、削らずに動かす） |
| 月表示・週表示 | カレンダーの見出しの横の「**月｜週**」で切り替え（キー `w`）。**週表示**は、日曜はじまりの1週間だけを大きく出し、予定は折り返して全文を見せる。`‹` `›`（キー ← →）は1週ずつ、「今日」は今日の週。選んだ表示は覚える。月のまとめは、その週の木曜日がある月の分 |
| 1日の高さは固定 | 月のカレンダーは、1日の高さを**約134px（従来より長め）で固定**。予定が増えても高さは変わらず、入りきらない予定（4件まで表示）は「**他 n件**」にまとまる（押すと、その日の予定がすべて開く。スマホは2件まで）。**完了した予定（ToDoが完了したもの）は、同じ日の中で、完了していない予定より下**に並ぶ。週表示も、予定の帯の高さは月と同じ（12件まで表示） |
| リスト | 「カレンダー / リスト」の切り替え。**リストタブは、ToDoのカンバン（未着手・進行中・完了）だけ**（予定の一覧は出さない。予定はカレンダーで見る）。リストでは、月の移動・「表示する人」・説明の帯も出ず、見出しは「ToDo（業務／プライベート）」になる。会社用の共有ページのリストだけは、今月の予定を日ごとに並べた一覧 |
| ToDoのカンバン | リストタブでは、ToDoを「未着手・進行中・完了」の3列で管理する。カードをドラッグして列を移せる（列の中での並べ替えも可）。スマホ幅では、列を並べずに状態のタブ（未着手／進行中／完了、件数つき）で切り替え、カードのボタン（進行中へ／完了／戻す）で移す（選んだタブは覚えている）。カレンダー横の細いToDo欄は従来どおりのリストで、進行中のToDoには「進行中」と表示される。ToDoは本人だけに見える |
| 業務のToDoの共有 | **業務のToDoは、社員全員（管理者も）に見える**。業務版のリスト画面に、他の人の業務のToDoが、持ち主の名前つきで出る（見るだけ。ドラッグ・完了・編集・削除はできず、押すと内容とメモが見られる）。上の「表示」で、**全員／自分だけ／○○さん**を選べる（初期値は自分だけ。選んだ状態は、開き直すと自分に戻る）。プライベートのToDoは、これまで通り本人だけ（プライベート版の追加欄で、「プライベート（自分だけ）」か「業務（全員に見える）」を選ぶ）。他の人の更新は、約20秒以内に自動で反映される。利用停止の社員のToDoは出ない |
| ToDoのコメント | **業務のToDoには、持ち主以外の社員も、コメントを付けられる**（編集・完了・削除はできない）。他の人のToDoのカードを押す、または自分のカードの「コメント」ボタンで、コメント欄が開く（500文字まで・Ctrl + Enter で送信・1つのToDoに200件まで）。カードに「💬 件数」が出て、**自分がまだ読んでいないコメントがあると、青い目印**が付く（約20秒以内に自動で反映）。コメントを消せるのは、**書いた人・ToDoの持ち主・管理者**。プライベートのToDoには付けられない。ToDoを削除すると、コメントも消える。コメントは、バックアップに含まれる |
| コメントの画像 | コメントに、**画像（スクリーンショットなど）を3枚まで添付**できる（PNG・JPEG・GIF・WebP）。「📎 画像を添付」で選ぶほか、**貼り付け（Ctrl + V）**や**ドラッグ**でも付けられる。文字なしで画像だけのコメントも可。ブラウザ側で長辺1600pxに縮めてから送り、サーバーでも検査して描き直す（中身が画像でないものは拒否。画像に仕込まれたものや写真の付随情報〔位置情報など〕は消える）。1つのToDoに30枚まで。画像は、サーバーの `data/attachments/`（Webから直接は見えない）に置き、**ログインして、そのToDoを見られる人だけ**が見られる（押すと大きく表示）。コメントやToDoを削除すると、画像も消える。**画像は、バックアップのファイルには含まれない**（バックアップは文字のデータだけ。画像が必要なら、`data/attachments/` を別にコピーする） |
| ToDoの追加 | 上の入力欄・追加ボタンは無く、**未着手の列（カレンダー画面のToDoパネルでは「未着手」）の一番下の「＋ 追加」**を押すと、その場に入力欄が開く（Enterで追加・Escかキャンセルで閉じる。追加後も開いたままなので、続けて入力できる。業務版では業務のToDo、プライベート版ではプライベートのToDoが作られる） |
| 保留・完了の畳み | ToDoのカンバンは、**未着手・進行中**の列と、右の列の**完了（ふだんは畳んである。見出しを押すと開く。開き畳みは覚える）**、その下の**保留**（しばらく手をつけないもの。カードの「保留」ボタン・ドラッグで移す）。保留は、カレンダーのToDoパネルには出ない |
| ToDoの完了 | ToDoの左のチェックで完了にすると、リストから消えて「完了したToDo」に移る（日付つき）。チェックを外せば戻り、まとめて削除もできる。今日完了した業務のToDoは、日報の雛形に取り消し線つきで入る |
| 共有リンク | ログイン不要・閲覧専用のURL。**家族用**はカレンダーだけ。自分の予定のうち、家族に共有すると決めたものだけが見える（プライベートは初期値が共有で、外した予定だけ隠れる。業務・休みは初期値が共有なし。既存の予定も、開いてチェックするか、「休みを全て／業務の分類ごと」でまとめて共有できる）。**会社用**（管理者）は、業務の予定と休みだけ。URLの作り直し・停止ですぐ見られなくなる |
| 予定の入力（分類・時刻） | 新しい業務の予定の**分類の初期値は「個人作業」**（休みから業務に切り替えたときも）。**開始時刻を入れると、終了時刻に、その30分後が自動で入る**（23:30 以降は 23:59 まで）。終了を手で入れたあとは、開始を変えても終了は変わらない。自動で入れた終了は、開始を消すといっしょに消える。繰り返し業務の登録の画面も、同じ |
| 共有ページから、自分の画面へ戻る | 共有リンク（家族用・会社用）のページを、**リンクを作った本人がログインしたまま**開くと、上に「← 自分の画面に戻る」が出る（家族用は、プライベート版へ。会社用は、業務版へ）。ほかの人・ログインしていない人には出ない（サーバーが返すのは、本人かどうかの true/false だけ） |
| 家族の招待（家族のアカウント） | 設定のページの「**家族の招待**」で、家族（**5人まで**）のアカウントを作る。名前とメールアドレスを入れて招待すると、**一時パスワードが1度だけ**表示される。**「招待メールも送る」（初めはオン）にすると、ログインのページ・メールアドレス・一時パスワードが、本人にメールでも届く**（サーバーの `mail()` で送る。送れなかったときは、画面にそう出るので、表示された内容を直接伝える。届かないときは、`config.php` の `mail_from` に、自分のドメインのアドレスを決める）（本人に伝える。最初のログインで、自分のパスワードに変える。「パスワードをリセット」「利用を止める／再開」「削除」もできる）。**家族のアカウントでできること**: ログインして、持ち主の**プライベートのカレンダーを見る**（持ち主が「家族に共有」にした予定と、共有リンクで共有している範囲、家族が入れた予定）。**自分の表示名を変える**（名前のメニューの「表示名の変更」。予定の先頭・持ち主の画面・家族の一覧に出る名前。家族が同じ名字でも、「ママ」のように見分けられる。持ち主のプライベート版では、家族の予定の先頭に、この表示名がそのまま出る）。**自分の予定を入れる・変える・消す**（いつも「プライベート・家族に共有」。ほかの人の予定は見るだけ）。**できないこと**: 業務・社員・ToDo・日報・会議室・設定・共有リンク・バックアップなど（画面にも出ず、サーバーも403で拒否）。家族が入れた予定は、**持ち主のプライベート版にも出る**（先頭に名前。見るだけ）。業務版・管理者・ほかの社員・ほかの持ち主の家族には見えない。家族の予定は、更新履歴・変更履歴には残さない。家族のアカウントは、社員の一覧・利用状況にも出ない（管理者は管理できない。持ち主が管理する） |
| ToDo | **リストタブ**で管理する（カレンダー画面には、ToDoもメモも出さない）。日付の決まっていないやることを置く（**ToDoは、業務版とプライベート版で分かれている**。業務版には業務のToDo（社員全員に見える。見るだけで、変えられるのは持ち主だけ）、プライベート版にはプライベートのToDo（本人だけ）。プライベート版には、日報メモは出ない。凡例・「○月のまとめ」も、プライベート版では出さない。凡例は、月の表示とカレンダーの間の、説明の帯の中に出る（広い画面では、説明・凡例・「ⓘ 使い方」が1行に並ぶ）。スマホでは、帯の長い説明は出さず、凡例だけ）。カードを**画面の右端まで持っていくと、カレンダーが開き**、日付にドロップして予定にできる（ドラッグ中に ‹ › へ乗せると月が切り替わる）。スマホなど、ドラッグしにくい端末は、カードの「日付」ボタン。**置いたToDoは消えず、自動で「進行中」になり、リストにも残る**（カードに置いた日が出る。もう一度置くと、予定は新しい日へ動く。置いたToDoの「日付」ボタンは、今の日付が入って開き、**「日付を外す」（または日付を空にして決定）で、カレンダーから外せる**。ToDoは残り、状態は変わらない）。**完了にすると、カレンダーの予定に取り消し線**が引かれる（未完了に戻すと消える。共有リンクにも同じ）。予定をToDoに戻すと、元のToDoに戻る（増えない）。ToDoを削除すると、結びついた予定はふつうの予定として残る。業務版には、業務のToDoだけを表示 |
| メモ（日報用） | リストタブのメモ欄。**1つの入力欄**に、日報の文章をそのまま書く（初めて開くと、「お疲れ様です。〜よろしくお願いいたします。」の雛形が入る）。文章の中の**「【10/13　予定・To Do】」の行（日付の行）が2つあり、上が当日、下が次回出勤日**で、日付は**自動で入れ替わる**（日付のあとの言葉「予定・To Do」や、挨拶・締めの文は、日報の中で**そのまま書き換えられる**。書き換えた言葉は、日付が入れ替わっても残る。「雛形の設定」で、いまの文面を自分の雛形として保存でき、「雛形に戻す」・初めて開いたときに使われる）（出勤日 = 土日祝・会社の休業日・自分の終日の休みを除く日。半休は出勤日。今日が休みなら、上が次の出勤日になる。日付の行は、直接は書き換えられない）。**日付の間の項目（当日の項目）のうち、取り消し線のないものは、次回出勤日の項目に自動で転記される**（一部でも取り消し線が付いた行は、転記されない）。転記された行は、左に細い線が付く。次回出勤日に自分で書いた行は消えず、同じ内容を自分で書いてあれば、重ねて足さない。**日が進むと、次回出勤日の項目が、当日の項目になる**（前の当日の項目は、取り消し線のないものが、すでに転記済み）。前の日の日報は、「過去の日報」に、120日分の控えが残る。項目は、空行を入れずに並べる（空行で、その見出しの項目が終わる）。いつもの日報の文章を貼り付けると、日付の入った【】の2行が、自動で日付の行になる。**スケジュールに入っている業務のToDoは、自動で日報に入る**（取り消し線なしで、当日または次回出勤日の項目に1行ずつ）: **進行中**のToDoは当日の項目に（カレンダーに先の日付で置いてあるものは、その日付の日報に）。**未着手**は、日付が決まっているものだけ、その日付の日報に（日付 = カレンダーに置いた日。置いていなければ期限日）。保留・完了は自動では入らない（完了は、完了にしたときに取り消し線つきで入る）。プライベートのToDoは入らない。一度入れたToDoは、日報から消しても入れ直さない（日付の行に控えを持つ）。日報に同じ文言の行があれば、重ねて足さない。ToDoのカードを欄にドラッグ&ドロップ（または、カードの「日報へ」）すると、その行が入り、**ToDoが完了なら取り消し線つき**、あとから進捗が変わると行も追従する（次回出勤日の見出しより下へ落とすと、次回出勤日の項目）。終わった業務に**取り消し線**を付けられ（行にカーソルを置いて押せば、その行全体）、「日報にコピー」で、全文を、メール等に貼っても取り消し線が残る形でコピーできる（書式つき + 文字だけ の両方）。「雛形に戻す」で、全文を雛形に置き換える。自動保存・本人だけに見える。以前の版のメモ・日ごとの日報は、最初に開いたとき、雛形に引き継がれる。**ToDoを完了にすると、日報の当日の項目にも、取り消し線つきで入る**（すでに日報にあれば、取り消し線にする。未完了に戻すと線は消える。業務のToDoだけ。取り消し線の行は、次回出勤日には転記されない） |
| 自動更新 | 他の人（同僚、共有リンクを見ている家族）が予定・ToDoを変えると、開いている画面に約20秒以内に自動で反映される（ページを開き直す必要なし）。変更があったときだけ読み直す・編集画面を開いている間やドラッグ中は画面を組み替えない・入力中のToDoの文字は消えない・非表示のタブでは確認しない。間隔は `config.php` の `poll_seconds`（5〜600、0で自動更新なし） |
| 予定の複製 | 予定を開いて「複製」→ 複製先の日付を選ぶ（複数日をまとめて指定可）。期間・時刻・メモを引き継ぐ。同じ予定がある日は飛ばす。休みは Slack に1通でまとめて通知 |
| 会社の休業日 | 右上の名前 →「会社の休業日」（管理者）。1日ずつだけでなく、**開始日〜終了日**で、年末年始などの続く休みをまとめて登録できる（最大60日間・すでにある日は飛ばす）。続く休みは1行にまとめて表示し、まとめて削除もできる。繰り返し業務の日付と、月のまとめの営業日に反映される |
| 文字の太さ | 画面全体の文字を、ふつうの太さ（以前は細め）から**やや太め（600）**にした。もともと太い見出し・ボタンなどは、そのまま。CSSの `--fw` で調整できる |
| カレンダーの右端のToDo | カレンダー画面の右端に「ToDo」の目印があり、**カーソルを持っていくと、ToDoのパネルが開く**（`d` キーでも開閉・Esc で閉じる）。パネルには、**「進行中」「未着手」の2つの欄**が（ToDoが無くても）常に出る。パネルでToDoの追加もでき、カードをカレンダーの日付へドラッグすると予定になる（ドラッグを始めると、パネルは脇へどく）。**カレンダーの予定を画面の右端まで持っていくと、同じパネルが開き**、「進行中」か「未着手」の欄（カードの前後でも可）にドロップすると、その状態のToDoになる。カーソルが離れると閉じる。リストタブでは出ない |
| Slack通知の設定・テスト（管理者） | 右上の **「設定」→「Slack通知の設定・テスト」**。送り先（Slack の Incoming Webhook URL）を、画面から登録・削除できる（`https://hooks.slack.com/services/…` の形だけ。URLは伏せて表示。画面の登録が `config.php` より優先）。**「テスト通知を送る」**で接続を確認し、通知の文面の見本は、「通知の時間・文面」の画面から送れる。失敗したときは、原因の案内が出る |
| 設定ボタン | 右上に「設定」ボタン（歯車の絵つき。スマホでは絵だけ）。押すと、**予定の色の設定・繰り返し業務の設定・共有リンク・ショートカットキー**が出る（管理者には、社員の管理・会社の休業日も）。ユーザー名のボタンには、パスワードの変更・繰り返し業務・ログアウトが並ぶ。どちらのメニューも、同時に開くのは1つだけ |
| 業務版・プライベート版の切り替え | 画面を作り直さず、**前に読んだ内容がすぐ出て**、あとから最新に差し替わる（初めてでも、カレンダーの枠は消えない）。もう一方の版は、裏で先に読んでおく。素早く往復しても、最後に選んだ版が表示される |
| バージョンの表示 | 画面左上の「スケジュール管理」の右横に、いまのバージョン（例: v1.41.0）が出る |
| ショートカットキー | `c` カレンダー／`l` リスト／`t` 今月に戻る／`←` `→` 前の月・次の月／`n` 予定を追加／`b` 業務版／`p` プライベート版／`?` 一覧。入力欄に文字を打っているとき・ダイアログを開いているとき・Ctrl/Alt/Command を押しているときは動かない。日本語入力がオンでも動く（キーの位置で判定） |

## セキュリティ

- パスワードは、元に戻せない形（`password_hash`）で保存。ログインは、失敗が続くと一時停止（15分のあいだに、同じメール・同じ接続元で8回／同じ接続元で30回／同じメールで接続元を問わず60回 → 15分。他人がわざと間違えて、本人を締め出せないよう、「8回」は、その接続元だけに効く。リバースプロキシの内側では `trust_forwarded_for` を設定）。パスワードを変えたら、ほかの端末のログインは終わる。ログイン時にセッションIDを作り直し、サーバーが発行していないIDは受け付けない。
- すべての変更操作に、画面ごとの確認用文字列（CSRF）を要求し、**変更の操作は POST だけ**を受け付ける（外のサイトのリンクを踏ませる GET では、何も書き換えられない。読むだけの操作だけ GET で使える）。データベースへの問い合わせは、すべて値を後から渡す形（SQLインジェクション対策）。画面への表示は、文字として出す（XSS対策）。
- 画面ごとの使い捨ての印（nonce）を付けた `<script>` だけを実行し、外部のスクリプト・通信・フォーム送信を許さない（`Content-Security-Policy`）。https のときは `Strict-Transport-Security` も送る。他のサイトの中に埋め込まれることも禁止。
- 他人のプライベート予定は、管理者も含め、サーバー側で返さない。共有リンクは、推測できない48文字のURLで、検索エンジンにも載せない。いつでも無効にできる。
- `config.php`・`src`・`sql` などは、`.htaccess` で外から開けないようにしている（`public/` の外に置く方式Aなら、そもそもURLがない）。
- `install.php` は、ユーザーが1人でも登録されると、接続先の書き換えを受け付けない。データベースに接続できないときなど、「ユーザーがいない」と確かめられないときも閉じたまま（消し忘れても、すり替えられない）。
- **管理者の画面から、プログラムを入れ替える機能は、ありません**（zip での更新は、廃止しました）。プログラムの更新は、GitHub から、テストに成功したものだけが、FTPS でサーバーへ自動で反映されます（接続情報は、GitHub の Secrets にだけあり、このアプリには入っていません）。一時パスワードのままでは、バックアップの画面は使えない。

## 動作環境

PHP 7.4 以上／ MySQL または MariaDB。必要なPHPの拡張: **pdo_mysql**（SQLiteで試すなら pdo_sqlite）、**mbstring**、**gd**（コメントの画像）、**openssl**・**zlib**（バックアップの暗号化と圧縮）、**curl**（Slack通知）。PHP 7.4 / 8.1 / 8.3 で、自動テストを流しています（`.github/workflows/test.yml`）。

```bash
# ブラウザで http://127.0.0.1:8080/install.php を開いて管理者を登録
```

## テスト

```bash
php tests/run.php                       # SQLite（一時DB）で実行
SCHEDULE_TEST_DSN='mysql:host=localhost;dbname=テスト用DB;charset=utf8mb4' \
SCHEDULE_TEST_USER=ユーザー SCHEDULE_TEST_PASS=パスワード php tests/run.php   # MySQLで実行（テスト用DBの中身は消えます）
```

祝日の計算、繰り返しルールの日付、プライベートが他人に漏れないこと、管理者の権限、繰り返し予定の個別編集・削除、Slack通知の二重送信防止などを確認します。

```bash
bash tests/e2e/run.sh                   # 画面テスト（Chromiumを動かす。40本ほど。SQLiteで自動）
bash tests/e2e/run.sh who sum           # 名前を指定して、それだけ
```

画面テストは、ログイン・カレンダー・ToDo・日報・共有リンク・バックアップなどを、実際の画面から操作して確かめます。必要なもの・MySQLで動かす方法・テストの一覧は [tests/e2e/README.md](tests/e2e/README.md) を見てください（本物の `data/` や `config.php` には触りません）。機能を変えたら、`tests/run.php` と両方を流します。

導入手順は [docs/DEPLOY.md](docs/DEPLOY.md) を見てください。
