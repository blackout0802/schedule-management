# スケジュール管理アプリ

会社の業務予定・休み（他の社員を含む）・プライベートの予定を1か所で管理する、小規模チーム向けのスケジュールアプリです。
PHP + MySQL だけで動くので、レンタルサーバーにアップロードして使えます（ビルド作業・Node.js は不要）。

## できること

| 機能 | 内容 |
|---|---|
| 業務版 | 会社の全員に見せる画面。**プライベートの予定は、サーバーが返さない**ため、画面を細工しても見えません |
| プライベート版 | 自分のプライベート予定に、見たい業務の予定（全体会議・打ち合わせなど）をタグで選んで重ねて表示 |
| 休みの管理 | 本人が登録。管理者は他の社員の休みも登録・編集できる（承認は不要） |
| カレンダー | 週ごとの表示。期間のある同じ業務は**1本のバーにまとめ**、土日祝・会社の休業日には出さない。予定はドラッグで別の日へ動かせる |
| リスト | 「カレンダー / リスト」の切り替え。リストタブは、ToDoのカンバン（未着手・進行中・完了）と、今月の予定を日ごとに並べた一覧 |
| ToDoのカンバン | リストタブでは、ToDoを「未着手・進行中・完了」の3列で管理する。カードをドラッグして列を移せる（列の中での並べ替えも可）。スマホ幅では、列を並べずに状態のタブ（未着手／進行中／完了、件数つき）で切り替え、カードのボタン（進行中へ／完了／戻す）で移す（選んだタブは覚えている）。カレンダー横の細いToDo欄は従来どおりのリストで、進行中のToDoには「進行中」と表示される。ToDoは本人だけに見える |
| ToDoの完了 | ToDoの左のチェックで完了にすると、リストから消えて「完了したToDo」に移る（日付つき）。チェックを外せば戻り、まとめて削除もできる。今日完了した業務のToDoは、日報の雛形に取り消し線つきで入る |
| 共有リンク | ログイン不要・閲覧専用のURL。**家族用**はカレンダーだけ。自分の予定のうち、家族に共有すると決めたものだけが見える（プライベートは初期値が共有で、外した予定だけ隠れる。業務・休みは初期値が共有なし。既存の予定も、開いてチェックするか、「休みを全て／業務の分類ごと」でまとめて共有できる）。**会社用**（管理者）は、業務の予定と休みだけ。URLの作り直し・停止ですぐ見られなくなる |
| ToDo | 右側の欄に、日付の決まっていないやることを置く（本人だけに見える）。日付へドラッグすると予定に、予定をドラッグで戻すとToDoに。ToDoの並べ替えもドラッグ。業務版には、業務のToDoだけを表示 |
| メモ（日報用） | ToDoの下のメモ欄。終わった業務に**取り消し線**を付けられ（行にカーソルを置いて押せば、その行全体）、「日報にコピー」で、メール等に貼っても取り消し線が残る（書式つき + 文字だけ の両方をコピー。文字だけの貼り付け先では、線の結合文字で取り消し線を表す）。「日報の雛形」で、本日と次の営業日の予定・ToDoを入れた下書きを作れる。自動保存・本人だけに見える |
| 自動更新 | 他の人（同僚、共有リンクを見ている家族）が予定・ToDoを変えると、開いている画面に約20秒以内に自動で反映される（ページを開き直す必要なし）。変更があったときだけ読み直す・編集画面を開いている間やドラッグ中は画面を組み替えない・入力中のToDoの文字は消えない・非表示のタブでは確認しない。間隔は `config.php` の `poll_seconds`（5〜600、0で自動更新なし） |
| システム更新 | 管理者メニューから、更新用の zip を選ぶだけでアプリを更新。更新前に自動でバックアップし、画面から元に戻せる |
| 予定の複製 | 予定を開いて「複製」→ 複製先の日付を選ぶ（複数日をまとめて指定可）。期間・時刻・メモを引き継ぐ。同じ予定がある日は飛ばす。休みは Slack に1通でまとめて通知 |
| 予定の種類の変更 | 登録した予定は、予定を開いて「業務・休み・プライベート」を選び直すと、あとから切り替えられる。変えられるのは予定の持ち主だけ（管理者でも他の人の予定の種類は変えられない）。プライベート→業務/休みは「全員に見える」確認つき。休みに変えたときは Slack にも通知。家族共有のチェックは、新しい種類の初期値に戻る |
| 毎月の繰り返し業務（入口） | 右上の名前 → 「繰り返し業務の設定」／ツールバーの「↻ 繰り返し業務」／新規予定ダイアログの「繰り返す場合は…」リンク／繰り返し予定を開いたときのリンク |
| 毎月の繰り返し業務 | 「月初3営業日」「10〜15日の営業日」「25日（休日なら前営業日）」などをルールで登録すると、12か月先まで自動で作成。土日祝・会社の休業日を避けて日付を計算 |
| Slack通知 | 休みの登録時、毎朝（本日の休み）、前日夕方（明日の休み）に通知。件名と日付だけを送り、休みの理由は載せない |
| ログイン | メールアドレス＋パスワード。管理者が登録した人は、初回ログイン時にパスワードの変更が必要（変更するまで他の操作はできない） |
| 権限 | 一般 / 管理者（社員の追加、他の社員の休みの登録、会社の休業日の設定）。管理者でもプライベートは見えない |

## 見える範囲のルール

| 予定の種類 | 本人 | 他の社員 | 管理者 |
|---|---|---|---|
| 業務 | 見える・編集可 | 見える | 見える・編集可 |
| 休み | 見える・編集可 | 見える | 見える・編集可 |
| プライベート | 見える・編集可 | **届かない** | **届かない** |

この判定は `src/events.php` の1か所だけで行っています。

## 構成

```
public/        画面とAPIの入口（公開する部分）
  index.php login.php logout.php install.php api.php app_path.php
  assets/app.js app.css
src/           アプリ本体（bootstrap / auth / events / recurrence / holidays / slack / api）
sql/           テーブル定義（MySQL用・SQLite用）
bin/cron.php   毎日動かす自動処理（繰り返し予定の作成・Slack通知）
tests/run.php  自動テスト
tools/make_update.py  更新用の zip（dist/update-v〜.zip）を作る
docs/DEPLOY.md スターレンタルサーバーへの導入手順
config.sample.php  設定ファイルの見本
```

## 動作環境

PHP 7.4 以上（PDO と pdo_mysql、curl があれば可）／ MySQL または MariaDB。

## 手元で試す

```bash
cp config.sample.php config.php
# config.php の db を SQLite にする:  'db' => ['dsn' => 'sqlite:' . __DIR__ . '/data/app.sqlite'],
php -S 127.0.0.1:8080 -t public
# ブラウザで http://127.0.0.1:8080/install.php を開いて管理者を登録
```

## テスト

```bash
php tests/run.php                       # SQLite（一時DB）で実行
SCHEDULE_TEST_DSN='mysql:host=localhost;dbname=テスト用DB;charset=utf8mb4' \
SCHEDULE_TEST_USER=ユーザー SCHEDULE_TEST_PASS=パスワード php tests/run.php   # MySQLで実行（テスト用DBの中身は消えます）
```

祝日の計算、繰り返しルールの日付、プライベートが他人に漏れないこと、管理者の権限、繰り返し予定の個別編集・削除、Slack通知の二重送信防止などを確認します。

導入手順は [docs/DEPLOY.md](docs/DEPLOY.md) を見てください。
