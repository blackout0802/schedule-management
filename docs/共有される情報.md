# 共有される情報・されない情報

「誰に何が見えるか」の一覧です（アプリの仕様を、コードに沿ってまとめたもの）。

凡例: ◎ 見える ／ △ 条件つきで見える ／ ✕ 見えない

## 1. 画面（ログインして使う）

| 情報 | 本人 | 一般の社員（他の人） | 管理者（他の人の分） |
|---|---|---|---|
| 業務の予定（件名・分類・日時・メモ・「重要」・色） | ◎ | ◎ 全員に見える | ◎（編集・削除もできる） |
| 休みの予定（誰が・分類〔有給・調整休など〕・期間） | ◎ | ◎ 全員に見える | ◎（他の社員の休みを登録・編集もできる） |
| プライベートの予定 | ◎ | ✕ | ✕（管理者にも見えない） |
| ToDo（未着手・進行中・完了） | ◎ | ✕ | ✕ |
| メモ（日報用） | ◎ | ✕ | ✕ |
| 月のまとめ（出勤日・休み・有給・欠勤の日数） | ◎ | ◎ 業務版では全社員分が見える | ◎ |
| 繰り返し業務のルール | ◎ | △ 予定として（↻付きで）見える | ◎ |
| 予定の色の設定 | ◎ | ◎ 色が反映されて見える | ◎ |
| メールアドレス・権限 | ◎ 自分の分 | ✕ 名前だけ見える | ◎（社員の管理） |
| パスワード | ✕ 本人にも見えない（暗号化して保存） | ✕ | ✕（リセットはできるが、元のパスワードは分からない） |
| 変更履歴（誰が・いつ・何を変えたか） | ✕ | ✕ | ◎ 管理者だけ（プライベート・ToDo・メモは記録しない） |
| 会社の休業日 | ◎ | ◎ | ◎（登録・削除は管理者のみ） |

## 2. 共有リンク（ログインなしで、URLを知っている人が見られる）

| 情報 | 会社用リンク | 家族用リンク（持ち主が作る） |
|---|---|---|
| 業務の予定 | ◎ 全社員分（件名・分類・日時） | △ 持ち主の予定のうち、「家族に共有」にしたもの／「見せる業務の分類」にしたものだけ |
| 業務の予定の「メモ」欄 | ✕ | △ 共有にした予定のメモは見える |
| 休みの予定 | ◎ 誰が・分類つき | △ 持ち主の休みを「すべて見せる」にしたときだけ。**「休み」とだけ表示**（種類・件名は出さない） |
| プライベートの予定 | ✕（絶対に含まない） | △ 持ち主が「家族に共有」にしたものだけ（**初期値は共有**。外した予定だけ隠れる） |
| 他の人の予定 | ◎（業務・休みのみ） | ✕ 持ち主の分だけ |
| ToDo・メモ | ✕ | ✕ |
| 更新履歴（追加・変更・削除の記録） | ✕ | △ 家族に見える予定の分だけ（件名・日付・変更内容）。持ち主が削除できる |
| 削除された予定 | ✕ | △ 家族が「確認」するまで、取消線で残る |
| 変更・編集 | ✕ 見るだけ | ✕ 見るだけ |

※ URLを知っている人はだれでも見られます。見せたい人にだけ伝え、漏れたときは「リンクを作り直す」で古いURLを使えなくしてください。

## 3. Slack・バックアップ

| 情報 | 内容 |
|---|---|
| Slack通知（朝・夕方） | 休みの人の**名前だけ**（分類・期間・@は出ない）、日付、「スケジュールを開く」のリンク（会社用リンクがあれば、そのURL）。送り先のチャンネルの全員に見える |
| Slack（バックアップのお知らせ） | 管理者が「Slackにも送る」にしたときだけ。月1回、バックアップの時期である旨と、バックアップ画面のURL |
| バックアップのファイル | 全データ（**プライベートの予定・ToDo・メモ・パスワードのハッシュを含む**）。パスワードで暗号化されており、パスワードを知らない人は、管理者でも読めない。`config.php` は含まれない |
| 自動バックアップ（サーバー内） | 同じ暗号化。パスワードがデータベースに保存される設定では、サーバーに侵入された場合に読まれる可能性がある（`config.php` に書く方式なら、データベースには残らない） |

## 4. 要点

- **プライベートの予定・ToDo・メモは、本人だけ**。管理者・変更履歴・会社用リンク・Slackには出ない（家族用リンクには、本人が共有にしたものだけ）。
- **業務の予定と休みは、社員全員に見える**。社外に出るのは、共有リンクを作ったときだけ。
- **家族用リンクは、「家族に共有」の初期値がプライベート=共有、業務・休み=非共有**。業務の共有は、持ち主が分類ごとに決める。
